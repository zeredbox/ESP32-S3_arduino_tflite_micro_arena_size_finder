# Modified Edge Impulse `tflite_micro.h`

This file is a **temporary diagnostic replacement** for the original Edge Impulse `tflite_micro.h`.

It is intended to be used with the following project:

**ESP32-S3 Arduino Tensor Arena Size Finder**  
https://github.com/zeredbox/ESP32-S3_arduino_tflite_micro_arena_size_finder

## Purpose

Edge Impulse automatically generates a Tensor Arena size for TensorFlow Lite Micro models. In some cases, this value may be too small, causing `AllocateTensors()` to fail before the actual memory requirement can be measured.

This modified `tflite_micro.h` temporarily overrides the Tensor Arena size with a larger diagnostic value and exposes the **actual Tensor Arena memory usage** after `AllocateTensors()` completes successfully.

This allows the Tensor Arena Size Finder sketch to:

- run even when the Tensor Arena generated by Edge Impulse is too small,
- measure the actual Tensor Arena memory usage,
- determine a more appropriate Tensor Arena size,
- calculate recommended **SMALL**, **MEDIUM**, and **LARGE** arena configurations.

## Important

> **Do not use this modified file permanently in your Edge Impulse project.**

Before using it:

1. **Make a backup** of the original Edge Impulse `tflite_micro.h` file.
2. Replace the original file with this modified version.
3. Run the Tensor Arena Size Finder diagnostic sketch.
4. Use the reported recommendation to update the Tensor Arena value in your Edge Impulse model header.
5. **Restore the original Edge Impulse `tflite_micro.h` file.**
6. Recompile and test your final project using the original Edge Impulse SDK files.

## Compatibility

This modified file was prepared for the **Edge Impulse SDK version used by this project**.

Future versions of the Edge Impulse SDK may modify the implementation of `tflite_micro.h`. As a result, this diagnostic replacement may no longer be compatible with newer SDK releases.

Always compare this file with the original `tflite_micro.h` included with your current Edge Impulse SDK before using it.
